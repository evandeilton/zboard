# zboard 0.0.0.9000

* Initial development version: the CRAN, GitHub and OpenAlex collectors
  (`collect_cran()`, `collect_github()`, `collect_academic()`), the
  consolidation pipeline with monthly rollups and 12-month retention
  (`consolidate()`), JSON export for the bilingual Quarto dashboard
  (`export_json()`), shields.io endpoint badges (`make_badges()`) and
  CRAN-check alerts as GitHub issues (`run_alerts()`).
